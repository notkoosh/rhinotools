Rhino Tools Wiki

Reference for a small set of Rhino3d Python scripts that turn a solid model of sheet-goods parts into something a laser cutter or CNC router can cut: finger joints, mortise and tenon joints, dogbone relief cuts, and flattening parts onto the Top plane.

Install & aliases See the workflow Video playlist
ELI5

You design a box or a piece of furniture in Rhino as if it were already glued together. These scripts then do the fiddly carpentry on the computer: they cut the fingers that let the panels lock together, make the little round notches a router needs to cut square corners, and lay every panel flat on the floor so the machine can cut it out of a sheet.

Install & aliases

Clone the repository, point a Rhino alias at each script, and run them like built-in commands.

1. Clone the repository

git clone https://github.com/notkoosh/rhinotools.git

Keep the folder layout as it is. Three scripts import the helper module getsubsurface from the same folder, and the two finger-joint scripts import finger.py from the fingerjoint folder. Rhino adds a script's own folder to the import path when it runs it, so the imports work as long as the files stay together.

2. Add aliases

Open Options → Aliases (Windows) or Preferences → Aliases (Mac). Each alias runs RunPythonScript with the full path to a script. The leading !-_ cancels any running command and suppresses the dialog. Replace the path with wherever you cloned the repository.

AliasCommand macroDoes

finger3!-_RunPythonScript (C:\path\rhinotools\fingerjoint\xyz.py)Finger-joint three mutually orthogonal sets
lay!-_RunPythonScript (C:\path\rhinotools\laydown.py)Lay panels flat on Top
dogbone!-_RunPythonScript (C:\path\rhinotools\dogbone.py)Dogbone an extrusion face
innerhole!-_RunPythonScript (C:\path\rhinotools\innerhole.py)Dogbone a hole curve
outerhole!-_RunPythonScript (C:\path\rhinotools\outerhole.py)Dogbone an outer-profile curve
mt (suggested)!-_RunPythonScript (C:\path\rhinotools\mortisetenon.py)Mortise and tenon
faces (suggested)!-_RunPythonScript (C:\path\rhinotools\faces.py)Thicken a surface shell inward

The first six names are the ones the author uses; the README only documents those. mt and faces are suggestions for the two scripts the README does not mention.

3. Check your Python engine

The scripts are written for IronPython 2.7: they use print "…" statements, reduce and reload. They run unchanged in Rhino 5, 6 and 7. Rhino 8 still ships the IronPython 2 engine and should run a plain .py file with it; if the editor offers a choice, pick IronPython 2, or put #! python 2 on the first line of the script.

4. Check your units

Workflow: from model to cutter

The tools are small on purpose. Together they take an assembled model of sheet-goods parts and hand you flat outlines ready to cut.

ELI5

Build the thing whole. Then: make the panels grab each other (joinery), fix the corners a round cutter cannot make (dogbones), and knock every panel flat (lay). Export the outlines. Cut.

  1. 1

    Model the parts as solids

    Each panel is an extrusion or an extrusion-like polysurface, exactly as thick as your sheet, sitting where it belongs in the assembly. Where two panels meet, let them overlap through each other: the joinery tools work on the overlapping volume. If you only have zero-thickness surfaces, faces can thicken them.

  2. 2

    Finger-joint the box

    finger3 for a full box, finger2 for a single L or T. The tools pick which part keeps which slice of the overlap, then subtract.

  3. 3

    Add shelves and dividers optional

    mortisetenon grows tabs out of one part and cuts matching slots through another. Draw the tab outlines on the face first.

  4. 4

    Relieve inside corners router only

    A laser leaves square corners, so skip this step for laser cutting. For a CNC router, run dogbone on every face with an inside corner that a mating part must fit into: finger notches, mortises, slots. See Why dogbones?

  5. 5

    Lay everything flat

    lay copies each panel onto the Top plane, face down, on its own layer. The originals stay hidden so the model survives.

  6. 6

    Nest, outline, export

    Arrange the flat copies on a sheet (by hand, or with a nesting plugin). Use Rhino's Make2D or DupBorder on the top faces to get curves, then export as DXF or PDF for your cutter. If you work with 2D curves instead of solids, innerhole and outerhole add dogbones directly to the curves.

TipSave before each boolean-heavy step. The joinery tools delete and recreate the parts they touch, so Undo works but is slow on large models.

Finger joints 101

What the finger-joint tools are actually building, and why they ask for an odd number.

concept
ELI5

Lace your fingers together. Each hand fills the gaps between the other hand's fingers, and the two hands cannot slide sideways. A finger joint (also called a box joint) does that with two plates: the end of one is cut into tabs, the end of the other into matching gaps.

Animationtwo plates, five fingers

What the tools compute

When two panels of the same thickness meet at a right angle and overlap, the overlap is a bar as wide as the sheet is thick and as long as the joint. The tools slice that bar into N equal pieces along the joint and give the pieces alternately to one panel and the other. Each panel then loses the pieces it was not given. Nothing else about the panels changes, so the joint fits exactly, with zero clearance.

  • Finger length equals sheet thickness. It cannot be anything else when the panels simply overlap.
  • Finger width is joint length ÷ N. You choose N (the "subdivisions" prompt), not the width. Pick N so the width is a comfortable size for your material.
  • Odd N looks right. With an odd count the two end pieces go to the same panel, so a box edge starts and ends with the same part showing. Even counts work but look lopsided.
  • No kerf or clearance. The joint is modelled tight. For a laser cutter the kerf usually gives you the slack you need. For a router you must dogbone the gaps and may want to offset outlines yourself.

Where to go next

HomeJoineryfinger2

finger2

Finger-joint two orthogonal sets of panels where they overlap.

alias finger2script fingerjoint/two.pydocumented
ELI5

Two boards cross through each other at a corner. Tell the tool which boards belong to which side, how many fingers you want, and draw a line along the corner. It slices the shared chunk into fingers and hands every other finger to the other board.

Animationan L joint with 5 subdivisions

Before you start

  • Both sets are closed polysurfaces (extrusions or boxes). The selection filter only accepts polysurfaces.
  • The two sets are perpendicular and physically overlap where the joint goes. No overlap, no fingers.
  • "Plane 1" and "plane 2" are just the two sides of the joint: for example all the horizontal shelves and all the vertical uprights. Several panels per side are fine; every pair that overlaps gets fingered.

Steps

  1. Run finger2. select plane 1 objects Pick the panels on one side of the joint, then Enter.
  2. select plane 2 objects Pick the panels on the other side, then Enter.
  3. enter subdivisions (odd) Type the number of fingers along the joint (default 5, minimum 2). Odd numbers give symmetrical ends; see Finger joints 101.
  4. select start of intersection and select end of intersection: click two points along an edge of the joint. Any edge of the overlapping bar works; what matters is the direction and the length. Snap to the ends of the joint so the fingers cover its whole length.
  5. The redraw pauses while the booleans run. When it returns, every overlapping pair has been fingered.

Prompts

PromptExpected inputNotes
select plane 1 objectsOne or more polysurfacesEven-numbered pieces (0, 2, 4…) are cut from these.
select plane 2 objectsOne or more polysurfacesOdd-numbered pieces (1, 3…) are cut from these.
enter subdivisions (odd)Integer ≥ 2Default 5. Number of pieces along the drawn line.
select start of intersectionPointUse osnaps. First end of the joint.
select end of intersectionPointOther end. The line between them is the slicing axis.

How it works

  • For every pair (plane 1 panel, plane 2 panel) the script computes their boolean intersection: the overlap bar.
  • It splits your line into N equal steps and, for each step, builds a big cylinder (radius 100 units) whose axis is the line and whose length is one step.
  • Each overlap bar is intersected with each cylinder, which cuts it into N pieces. Even pieces are queued for subtraction from the plane 1 panel, odd pieces from the plane 2 panel.
  • Finally every panel has its queued pieces subtracted in one BooleanDifference.

Tips and gotchas

  • Draw the line the full length of the joint. Fingers only exist along the line. A short line leaves the ends of the overlap in place as a solid lump.
  • Keep panels within 100 units of the line. The slicing cylinders have a fixed radius of 100 model units (finger.py:64). In millimetres that is only 10 cm; see units.
  • No kerf compensation. The joint is modelled with zero clearance. For a router, run dogbone on the finger notches afterwards.
  • Several panels per side is the point. A T-shaped shelf through an upright is one call: shelf on side 1, upright on side 2.
  • A failed boolean (non-manifold input, coincident faces that do not quite overlap) leaves the pair untouched; check for stray pieces afterwards.

Known issues

  • You choose finger count, not finger width. TODO
  • No kerf control. TODO
  • The joint axis must be drawn; it is not derived from the geometry. TODO

finger3

Finger-joint three mutually perpendicular sets of panels: the box case.

alias finger3script fingerjoint/xyz.pydocumented
ELI5

A box has panels facing three ways: left-right, front-back, up-down. This tool runs finger2 three times, once for each pair of directions, and hides the third set each time so you can see the edge you need to draw.

Animationthree passes, then one subtraction

Before you start

  • Sort your panels mentally into three sets by the direction they face: X (their faces point along the X axis), Y and Z. Sides of a box are X and Y; top and bottom are Z.
  • All panels are polysurfaces and every pair of sets overlaps where they meet.
  • The same subdivision count is used for all three edges. If your box is not a cube, finger widths will differ per edge.

Steps

  1. Run finger3. select X objects, then select Y objects, then select Z objects. Enter after each set.
  2. enter subdivisions (o) Number of fingers per edge (default 5). Odd is best.
  3. Pass 1. The Z set disappears. select start of intersection / end: click along a vertical edge where an X panel meets a Y panel.
  4. Pass 2. Z is back, Y is hidden. Click along an edge where an X panel meets a Z panel.
  5. Pass 3. X is hidden. Click along an edge where a Y panel meets a Z panel.
  6. Everything reappears and all the pieces are subtracted in one go.

Prompts

PromptExpected inputNotes
select X objectsPolysurfacesPanels whose faces point along X.
select Y objectsPolysurfacesPanels whose faces point along Y.
select Z objectsPolysurfacesPanels whose faces point along Z (top, bottom, shelves).
enter subdivisions (o)Integer ≥ 2Default 5, used for all three passes. The "(o)" means odd.
select start / end of intersectionTwo points, three timesPass 1: X∩Y edge. Pass 2: X∩Z edge. Pass 3: Y∩Z edge.

Which part keeps which finger

The passes run as (X, Y), (X, Z), (Y, Z). In each pass the first-named set plays "plane 1" and loses the even-numbered pieces. So X panels get notched at both ends of their joints with Y and Z, and Y panels get notched at the ends of their joints with Z. If a corner comes out the other way from what you wanted, swap which set you call X and which Y.

Tips and gotchas

  • Only three edges to draw, not twelve: one edge per pair of sets is enough because every overlapping pair in those sets is handled along the same direction.
  • Draw each edge the full length of the box in that direction; fingers exist only along the line.
  • The hiding is only there to help you click. It is undone before the booleans run.
  • All the caveats of finger2 apply: 100-unit cylinder radius, no kerf, zero clearance.

mortisetenon

Grow tenons from a face of one part and cut matching mortises through another.

alias mt (suggested)script mortisetenon.pyundocumented in README
ELI5

Draw rectangles on the end of a board where you want pegs. Point at how far the pegs should stick out. The tool pushes the rectangles out into pegs, glues them onto the board, and punches the same shapes through the other part so the pegs have holes to go into.

Animationtwo through-tenons from an upright into a shelf

Before you start

  • The positive part gets the tenons. The negative part gets the mortises. Both are polysurfaces.
  • Draw the tenon outlines as closed curves (rectangles, usually) lying on the positive part's face before running the tool. Rhino cannot draw while a script is waiting for a selection.
  • Decide how long the tenons are: for through-tenons, the far face of the negative part; for blind tenons, any point at the right depth.

Steps

  1. Run the alias. select positive object Pick the part that gets the tenons.
  2. select negative object Pick the part that gets the mortises. It is hidden for the next two prompts so it cannot get in the way.
  3. select tenon surface Click the face of the positive part the tenons grow from. This uses getsubsurface, so click the face itself. The construction plane snaps to that face.
  4. select tenon curves Select the closed curves you drew on that face, then Enter. The negative part reappears.
  5. enter height point Click a point. Its distance from the face plane is the tenon length. Snap to the far face of the negative part for a through-tenon.
  6. The tenons are extruded, unioned into the positive, and subtracted from the negative. Original objects are replaced.

Prompts

PromptExpected inputNotes
select positive objectOne polysurfaceReceives the tenons.
select negative objectOne polysurfaceReceives the mortises. Hidden until the curves are picked.
select tenon surfaceOne face of the positive partSets the CPlane and the extrusion direction (the face normal).
select tenon curvesClosed planar curvesEach becomes one tenon. Project osnaps are turned on so points land on the face plane.
enter height pointPointOnly its distance from the face plane matters, measured along the normal.

How it works

  • The clicked face gives a plane and its normal. Each curve is turned into a planar surface and extruded along the normal by the height point's distance to the plane.
  • BooleanUnion(positive + tenons) builds the new positive; BooleanDifference(negative, tenons) builds the new negative. Both are created as new objects and the inputs are deleted.

Tips and gotchas

  • Zero clearance. The mortise is exactly the tenon. For a tight friction fit that is what you want; for a slip fit, offset the curves outward before cutting the negative, or rely on the laser kerf.
  • Router users: dogbone the mortises. A rectangular mortise has four inside corners. Run dogbone on the negative part's face afterwards.
  • The tenon curves must lie on the face (or be projectable onto it); a curve floating above the face still extrudes, but from where it is.
  • If the union fails, the tenon probably sits flush inside the positive part rather than protruding; check the height point was on the far side of the face.

Why dogbones?

A router bit is round. Inside corners are not. Something has to give.

concept
ELI5

Try to colour the corner of a square with a round crayon tip without going outside the lines. You can't; the corner stays white. A router bit is a spinning round crayon, so every inside corner it cuts stays slightly round, and the square tab that is supposed to fit there jams. A dogbone is a deliberate extra bite at the corner, placed so the round bit can go past the corner and clear it.

Animationa slot, a round cutter, and the fix

What these tools build

All three dogbone tools place the same shape at each corner you pick: a circle whose diameter is the cutter diameter plus ten percent, centred on the 45° diagonal of the corner, offset into the material by its own radius. The circle therefore passes exactly through the original corner point, and a cutter following the new outline reaches the corner. The ten percent is clearance for cutter runout and material fuzz.

ToolWorks onCorner pickingResult
dogboneA face of a 3D extrusionClick corners, or Esc for auto-detectCylinders subtracted through the solid
innerholeA closed polyline that is a holeClick cornersCircles unioned into the curve (hole grows)
outerholeA closed polyline that is an outer profileClick cornersCircles subtracted from the curve (notches grow)

When you do not need them

  • Laser cutting. A laser kerf is a fraction of a millimetre and the corner comes out sharp. Skip dogbones.
  • Outside corners. A round cutter goes around an outside (convex) corner perfectly well. Only inside (concave) corners need relief.
  • Corners nothing fits into. If no mating part has to seat in the corner, a small radius is harmless.

Further reading

The README points to an explanation of slotted construction and relief cuts at kontraptionist.com.

dogbone

Cut dogbone relief into the inside corners of a planar face of a solid.

alias dogbonescript dogbone.pydocumented
ELI5

Click the face of the panel the router will cut from. Tell the tool how fat the bit is. Click the inside corners. It drills a bit-sized hole diagonally into each corner, right through the panel, so the bit can reach. It also leaves a tiny marker where each corner used to be, in case you need it later.

Animationa slot through a panel, four corners

Before you start

  • The part is a closed polysurface with a planar face that contains the corners: the face the cutter enters from.
  • Know your cutter diameter in model units. The default offered is 0.25 (a quarter-inch bit).
  • The panel must be less than 10 units thick, or edit the cylinder height first. See units.

Steps

  1. Run dogbone. select dogbone face Click the planar face. If a plain click grabs the whole solid, use sub-object selection (Ctrl+Shift+click on Windows, ⌘+Shift+click on Mac).
  2. enter cutter diameter Type the bit diameter. The tool multiplies it by 1.1.
  3. The construction plane aligns to the face and project osnaps turn on. select corner Click each inside corner you want relieved; a red dot confirms each pick. Points that are not a corner of the face's outline are rejected with "invalid curve point".
  4. Press Esc (or Enter) to finish picking. If you picked nothing, the tool auto-detects corners that turn one way around each outline and dogbones all of them.
  5. Cylinders are placed and subtracted. The original part is replaced by the result; previously hidden objects are re-hidden; a point object marks each original corner on the dogbone-ref layer.

Prompts

PromptExpected inputNotes
select dogbone faceOne planar face of a polysurfaceVia getsubsurface. Its outer border and any inner borders (holes) become the candidate outlines.
enter cutter diameterNumber, default 0.25Used as 1.1 × diameter.
select cornerPoints, repeated; Esc to stopMust coincide (to 4 decimals) with a vertex of a border curve. Use End or Point osnap.

How it works

  • The face is duplicated as a standalone surface; its outer and inner borders are duplicated as polylines and their vertices cached.
  • For every picked vertex the script measures the corner angle, finds the bisector pointing into the material, and places a circle of radius ½ × 1.1 × diameter at ½ × 1.1 × diameter from the corner along that bisector. The circle passes through the corner.
  • Each circle is extruded from 10 units below the face to 10 units above, in the face's construction plane, and all the cylinders are subtracted from the part in one BooleanDifference.
  • Auto-detect uses the sign of the turn at each vertex (the z component of the cross product of the two edges). Which sign means "inside corner" depends on the direction the border curve runs, which is why it sometimes picks the wrong corners.

Tips and gotchas

  • Auto-detect picked the wrong corners? Undo and run again clicking the face from the other side of the panel, or just click the corners you want. FIXME
  • Circles landed on the wrong side of a corner? The handedness guess failed for that outline. Undo, and try selecting the opposite face. FIXME
  • Nothing happened? Check that your picks snapped to actual vertices; the command line prints invalid curve point for misses.
  • The dogbone-ref points are handy for dimensioning the original corner later. Delete the layer if you do not want them.
  • Finger-joint notches, mortises and slots all have inside corners. Run this on every face a mating part seats into.

innerhole

Add dogbone relief to the corners of a closed curve that represents a hole or pocket.

alias innerholescript innerhole.pydocumented
ELI5

You have the outline of a hole drawn as a shape. Click its corners. The tool adds a round bump at each corner, pointing away from the hole, and merges the bumps into the outline so the hole gets a little bigger exactly where the router bit needs room.

Animationa rectangular hole, four corners

Before you start

  • The input is one closed polyline. The script reads the curve's control points as corners, so a smooth curve will not give sensible results.
  • Turn on the End or Point osnap: picks must land exactly on a vertex.
  • The curve should describe empty space (a hole, slot or pocket), with material around it.

Steps

  1. Run innerhole. enter cutter diameter Type the bit diameter (default 0.25). It is used as 1.1 × diameter.
  2. select object Pick the closed polyline.
  3. select point Click a corner. The command line prints clicked index n for a hit, invalid point for a miss. Repeat for every corner you want relieved.
  4. Press Esc to finish. The circles are unioned with the curve and the inputs deleted, leaving one new closed curve.

Prompts

PromptExpected inputNotes
enter cutter diameterNumber, default 0.25Multiplied by 1.1.
select objectOne closed polylineCurve filter only.
select pointVertices, repeated; Esc to stopExact match against the curve's control points.

How it works

  • At each picked vertex, the angle between the two adjacent edges is halved to find the bisector; a circle of radius ½ × 1.1 × diameter is placed that far from the vertex along the bisector, so it passes through the vertex.
  • CurveBooleanUnion(circles + curve) merges everything into one outline. Because the circles sit outside the hole, the hole grows at the corners.

Tips and gotchas

  • Bumps pointing the wrong way? The bisector direction follows the curve's direction. Run Rhino's Flip on the curve and try again. FIXME
  • Picked the wrong corner? There is no undo inside the command; press Esc, undo, and start again.
  • Works on any closed polyline, not just rectangles: an L-shaped pocket is fine, just click the inside corners.

outerhole

Add dogbone relief to the inside corners of a closed curve that represents a part's outer profile.

alias outerholescript outerhole.pydocumented
ELI5

This is the outline of the whole part, and it has notches in its edge where other parts slot in. Click the corners at the bottom of each notch. The tool bites a round chunk out of the outline at each one so the router bit can clear the corner.

Animationa part outline with one slot

Before you start

  • The input is one closed polyline describing material, with notches or slots cut into its edge.
  • Only concave (inside) corners need relief. Convex corners of the outline do not; leave them alone.
  • Turn on the End or Point osnap.

Steps

  1. Run outerhole. enter cutter diameter Type the bit diameter (default 0.25). Used as 1.1 × diameter.
  2. select object Pick the closed polyline.
  3. select point Click each inside corner. clicked index n confirms a hit.
  4. Press Esc. Each circle is subtracted from the profile in turn, replacing the curve.

Prompts

PromptExpected inputNotes
enter cutter diameterNumber, default 0.25Multiplied by 1.1.
select objectOne closed polylineCurve filter only.
select pointVertices, repeated; Esc to stopExact match against control points.

How it works

Identical circle placement to innerhole; the only difference is the last step, which uses CurveBooleanDifference(profile, circle) once per circle instead of a union. The material shrinks at each corner.

Tips and gotchas

  • Bites on the wrong side? Flip the curve and try again.
  • Because each circle is subtracted separately, the script leaves exactly one curve at the end, but intermediate curves are created and deleted; expect several Undo steps.
  • If a circle overlaps a convex corner of the outline it may cut into the part where you do not want it. Pick carefully with a large cutter.

lay

Lay panels flat on the Top construction plane, one click per part.

alias layscript laydown.pydocumented
ELI5

Your model is standing up like a finished box. The laser needs every panel lying flat on the floor. Click each panel on the side that should touch the floor, and a copy of it lies down. Keep clicking until you run out of panels.

Animationone panel laid onto Top

Before you start

  • Parts are polysurfaces with a planar face to lie on (any flat panel qualifies).
  • Decide which face of each part is the "down" face. For parts with a good side, the down face is the one you want against the machine bed. Picking the other face mirrors the part.

Steps

  1. Run lay. A layer named laydown is created if needed.
  2. select down face Click the face of a part that should lie on the Top plane. A copy of the part is oriented so that face lies on Top, moved to the laydown layer, and the original is hidden.
  3. Repeat for every part. Each original disappears as you go, so you can see what is left.
  4. Press Esc when done. The command ends with an error message; this is expected and harmless. FIXME
  5. Run Show to bring the originals back when you want them.

Prompts

PromptExpected inputNotes
select down faceOne face of a polysurface, repeatedVia getsubsurface. Esc ends the loop (with the error noted above).

How it works

  • The clicked face defines a plane; the view's construction plane is set to it and the part's bounding box is computed in that plane.
  • Three corners of that box are mapped to the face's own surface coordinates with z = 0, and OrientObject (copy mode) maps the part from the first three points to the second three. The result is the part lying on world XY.

Tips and gotchas

  • Copies land near the origin and may overlap. Their position comes from the face's surface parameters, not from any nesting logic. Drag them apart or hand them to a nesting tool afterwards. The README recommends RhinoNest if you can afford it.
  • Keep the Top viewport active or at least check the result in Top; the construction plane of the active view is changed during the command.
  • The copies are on their own layer so you can select them all at once for Make2D or export.

faces

Thicken a shell of zero-thickness surfaces into solid panels, growing inward.

alias faces (suggested)script faces.pyexperimental
ELI5

You drew a box out of paper-thin sheets. This turns each sheet into a real plank, a quarter of a unit thick, pushing the thickness toward the inside of the box so the outside dimensions stay the same.

Animationan open box of five surfaces
StatusNot mentioned in the README, hardcoded thickness, and the file carries an old commented-out copy of the finger-joint code at the bottom. Treat it as a sketch that happens to work.

Steps

  1. Run the alias. select surfaces Select the surfaces that make up the shell, then Enter.
  2. Each surface is replaced by an extrusion 0.25 units thick, grown toward the shell's centre.

How it works

  • The centre of the shell is the average of every surface's midpoint.
  • For each surface, the script takes both candidate normals and keeps the one pointing toward that centre (the one whose dot product with the centre-to-surface vector is smaller).
  • The surface is extruded 0.25 units along that normal and the original surface deleted.

Tips and gotchas

  • Thickness is hardcoded at faces.py:32. Change 0.25 to your sheet thickness.
  • Works best on convex shells (a box). For an L-shaped or very lopsided arrangement, "toward the centre" may be the wrong side for some faces.
  • After thickening, the panels only touch at their edges; they do not overlap. The finger-joint tools need overlap, so scale or move panels so they interpenetrate by one thickness before running finger3.

getsubsurface

The shared helper that lets a script ask for one face of a solid.

module getsubsurface.pyfunction GetSubSurface(prompt)internal
ELI5

Rhino normally selects whole objects. This little helper says "no, I want to know which side of the object you clicked", and hands back both the object and a copy of that side as its own surface.

What it returns

from getsubsurface import GetSubSurface
polysurface_id, face_id = GetSubSurface("select down face")
  • polysurface_id: the object you clicked on.
  • face_id: a new, standalone surface object duplicated from the face you clicked. Callers use it to get a plane and a normal, then delete it.

Used by

dogbone"select dogbone face" lay"select down face" mortisetenon"select tenon surface"

How it works

It builds a RhinoCommon GetObject with the geometry filter set to Surface. With that filter Rhino lets you pick a face of a polysurface directly, and the returned object reference knows which face it was. Face().DuplicateFace(True) copies that face into a new Brep that is added to the document.

Why Esc produces an error

If you cancel at the prompt there is no picked object, and go.Object(0) raises an exception instead of returning None. The callers never see the None they test for, so the script ends with a traceback in the command history. Nothing is harmed; the work done before the cancel stays. The fix is to check go.Get()'s result before reading the object. FIXME

Selecting a face in Rhino

A plain click on the face usually works because the filter asks for surfaces. If Rhino insists on highlighting the whole solid, use sub-object selection: Ctrl+Shift+click on Windows, ⌘+Shift+click on Mac. The README mentions needing a third modifier on the author's setup, so your mileage may vary.

Glossary

The Rhino and workshop words these pages lean on. Dotted-underlined terms elsewhere in the wiki link here.

Alias
A short name you type at Rhino's command line that expands to a longer command macro. Set up in Options → Aliases. See Install.
Boolean union / difference / intersection
Solid modelling operations: union fuses solids into one, difference subtracts one from another, intersection keeps only the volume they share. The joinery tools are built out of these three.
Construction plane (CPlane)
The working plane of a viewport. Several tools set it to the face you clicked so that points and curves land on that face.
Dogbone
A round relief cut at an inside corner, placed on the corner's diagonal, so a round cutter can clear the corner. Named for the shape a slot takes with one at each end. See Why dogbones?
Endmill (router bit)
The rotating cutter in a CNC router. It has a diameter, so it can never cut a sharp inside corner.
Extrusion
A solid made by pushing a flat profile straight along a direction. Boxes and panels made with ExtrudeCrv are extrusions. The tools accept extrusions and extrusion-like polysurfaces interchangeably.
Finger joint (box joint)
A corner joint where each board has square tabs that fit into the other's gaps. See Finger joints 101.
IronPython 2.7
The Python implementation inside Rhino 5 to 7 (and still available in Rhino 8). These scripts use Python 2 syntax and must run on it.
Kerf
The width of material a cutter removes. A laser kerf is about 0.1 to 0.3 mm and often provides just enough slack for a tight-modelled joint. A router kerf is the bit diameter and must be handled by the toolpath software.
Layer
Rhino's way of grouping objects. The tools create laydown and dogbone-ref.
Mortise and tenon
A joint where a tab (tenon) on one part fits a matching hole (mortise) in another. See mortisetenon.
Osnap (object snap)
Snapping the cursor to geometry such as endpoints. The dogbone tools need you to snap exactly to vertices. "Project osnaps" flattens snapped points onto the construction plane.
Polyline
A curve made of straight segments. Its control points are its corners, which is what the 2D dogbone tools use.
Polysurface (Brep)
A solid or shell made of several joined surfaces. Extrusions, boxes and boolean results are all polysurfaces. Selection filter 16 in rhinoscriptsyntax.
Sub-object selection
Selecting part of an object (one face, one edge) rather than the whole thing. Ctrl+Shift+click on Windows, ⌘+Shift+click on Mac.
Subdivisions
What the finger-joint tools call the number of fingers plus gaps along a joint.

About this wiki

One HTML file, no build step, lives in the repository under docs/.

How it is built

  • Every page is an <article class="page" id="page-…"> in docs/index.html. The address bar hash picks which one is shown, so #dogbone is a link to the dogbone page from anywhere, including other pages' "See also" cards.
  • Animations are inline SVG driven by CSS keyframes on a single timeline per scene, so they loop, can be paused and replayed, and show the finished state when the viewer prefers reduced motion.
  • Colours come from a token block at the top of the stylesheet and follow the system light or dark theme.
  • Search filters the left-hand tree by title and by the hidden keywords on each entry.

Adding a page

  1. Copy an existing <article>, give it a new id="page-yourtool" and data-title.
  2. Add a <li> to the matching group in the <nav> with href="#yourtool" and some data-k keywords.
  3. Link to it from related pages with <a class="cmd" href="#yourtool"> or a "See also" card.

Hosting it publicly

Enable GitHub Pages for the repository and point it at the docs/ folder on the default branch. The wiki will appear at https://notkoosh.github.io/rhinotools/. Any static host works the same way, since the page needs nothing but itself and Google Fonts.
